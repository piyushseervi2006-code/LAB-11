# LAB-11 – User Information Form

## About the Project
This project is a User Information Form developed using HTML, CSS and PHP as part of the Web Technology Laboratory.

The form collects personal information from users and displays the submitted details on a separate output page.

## Objective
To design a user information form and process the submitted data using PHP.

## Technologies Used
- HTML5
- CSS3
- PHP

## Features
- User name input
- Gender selection (Male, Female, Other)
- Mobile number input
- Email address input
- City, State and Country fields
- Submit and Reset buttons
- Displays submitted information on a separate output page
- Styled user-friendly interface

## Form Fields
1. Name
2. Gender
3. Mobile
4. Email
5. City
6. State
7. Country

## How It Works
1. The user opens the input form.
2. The user enters the required information.
3. The form submits the details using the POST method.
4. PHP processes the submitted information.
5. The output page displays all the entered details in a table.

## How to Run
1. Save all project files in one folder.
2. Use a PHP-supported web server.
3. Open `index.html` through the PHP server.
4. Fill in the user information.
5. Click Submit to view the output.

## Learning Outcomes
- Understanding HTML forms.
- Using CSS for webpage styling.
- Understanding PHP variables and functions.
- Processing form data using the POST method.
- Displaying submitted information using PHP.
